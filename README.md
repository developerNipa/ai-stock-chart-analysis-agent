## 📌 Project Overview

An AI-powered workflow built with **n8n, Google Gemini, and custom chart data tools** that transforms stock-related questions into structured technical analysis.

The workflow connects an AI agent to market chart data tools, helping users explore price trends, support and resistance levels, MACD indicators, and other technical observations without manually collecting and reviewing all the data.

## ⚙️ How It Works

1. **User Query** — The user submits a stock-related question.
2. **AI Agent** — Understands the request and determines what information is needed.
3. **Custom Chart Data Tool** — Retrieves the relevant market and chart data.
4. **Google Gemini** — Analyzes the available data and generates technical insights.
5. **Structured Response** — Returns the analysis in an understandable format.
6. **Conversation Memory** — Maintains context across recent messages.

## 📊 Analysis Features

- 📈 Price trend analysis
- 🎯 Support and resistance levels
- 📉 MACD indicator analysis
- 🔍 Key technical levels
- 💡 Market observations
- 💬 Context-aware conversations using memory

## 🎯 Project Goals

- Automate the collection and analysis of chart data.

- Maintain conversational context across recent questions.
- Demonstrate how AI agents can coordinate multiple workflow components.

## ⚠️ Important Disclaimer

This workflow provides automated technical analysis and market observations for informational and educational purposes only. It does not guarantee future price movements and should not be treated as personalized financial advice.
